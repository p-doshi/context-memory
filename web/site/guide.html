Context Memory Harness

Replicate it

Six commands give you your own memory of your Claude Code sessions, code and notes, searchable from Claude Code. No code to write; each step ends with a check you can see.

You need: Windows, macOS or Linux; about 3 GB of disk; an internet connection for the install and the one-time model download. An NVIDIA GPU makes indexing faster but is not required. Everything stays on your machine.

  1. Install uv

    uv installs the exact Python and library versions this project was tested with.

    macOS / Linux

    curl -LsSf https://astral.sh/uv/install.sh | sh

    Windows (PowerShell)

    powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

    Check: uv --version prints a version.

  2. Get the code and its locked dependencies

    git clone https://github.com/p-doshi/context-memory
cd context-memory
uv sync --locked --extra embed

    Check: uv run cmh --help lists the commands.

  3. Tell it what to remember

    Point it at a code repository and a folder of notes (either is optional). It finds your Claude Code sessions by itself and fetches the embedding model once.

    uv run cmh init --code ~/projects/my-repo --docs ~/notes --download-model

    Check: it prints the config file it wrote and "embedding model ready".

  4. Build the memory

    uv run cmh daemon --once

    Check: uv run cmh stats shows documents and chunks.

  5. Search it

    uv run cmh search "how did I set up the training loop" --mode hybrid

    Check: results with their source file or session and a verified / stale / unverified label.

  6. Connect Claude Code

    claude mcp add context-memory -- uv run --directory "$(pwd)" cmh serve

    Check: in Claude Code, /mcp lists context-memory; ask it to "search my memory for …".

  7. Optional: keep it running and use it from other machines

    An always-on daemon re-indexes every few minutes, and a hub lets Claude Code on servers and other laptops search it over SSH, with a short memory summary at the start of every session. On Windows: powershell -ExecutionPolicy Bypass -File scripts\install-daemon.ps1. Elsewhere, run uv run cmh daemon under your own process manager (no service file is provided yet). Remote machines: see docs/remote-setup.md.
