1.0 The path

Six stops. Each one answers a worry.

  1. 01 · Sources

    Everything you already use

    Claude Code sessions from every machine, claude.ai and Perplexity chats, git repositories and Markdown notes. Nothing changes in how you work; the memory reads what is already there.

    sources today: 6

  2. 02 · SSH link

    Security? Nothing is open to the internet.

    Other machines reach the memory through SSH, each with its own key and a token you can revoke. The memory listens only on the laptop itself; SSH accepts the home network only, and a firewall rule stops the memory's own software from calling out.

    ports open to the internet: 0

  3. 03 · Hub

    Who is asking, and what may they see?

    Every request carries a device token with a scope: read, write, upload, or admin. Every call is written to a tamper-evident log where each entry seals the one before it.

    scopes: read · write · upload · admin

  4. 04 · Disclosure gate

    Privacy? Personal details are cut out first.

    Before anything reaches a cloud model, a filter outside any AI removes e-mail addresses, phone numbers, street addresses, GPS coordinates, card and bank numbers, ID numbers and passwords.

    gate on this request: –

  5. 05 · Search

    Latency? It runs on a laptop GPU.

    Meaning-based search and keyword search run together and their rankings are merged, so exact names and fuzzy questions both work. On 30 test questions the right document was in the top five 90% of the time.

    search on this request: –

  6. 06 · Verify

    Accuracy? Old facts mark themselves.

    Each passage carries its source. Passages from files are re-checked against the file when used and marked verified, stale or missing, so an assistant can tell current knowledge from outdated.

    verified on this request: –

  7. 07 · Answer

    Cost? Nothing per question.

    The assistant gets the best passages with their sources. The embedding model and this site's answer model share one 6 GB laptop graphics card: no paid API, no subscription.

    monthly cost: $0

2.0 Questions

What people ask first.

Short answers, each with the number behind it. Live numbers come from the running system; the others from the project's own measurements, linked in the technical details below.

01

Where does my data live?

In one SQLite file and one vector index on your laptop, outside synced folders. Daily snapshots are verified by re-reading them.

cloud databases: 0

02

Which companies see it?

Only the assistants you already use see what you ask them, filtered by the gate. The full list of outside parties, and what each receives, is published in the repository.

hosted AI in between: 0

03

How fast is it?

A warm search on the laptop took 152 ms at the median, and 219 ms from a lab server through the SSH tunnel.

this page's search: –

04

Can an answer be wrong?

Yes, which is why every answer cites its passages and every file passage says whether the file still matches.

states: verified · stale · missing

05

What does it run on?

A laptop with a 6 GB graphics card (a GTX 1660 Ti here). It runs around the clock as a background service.

public passages searchable now: –

06

Do my agents need changes?

No. Claude Code connects to it as an MCP server. Agents reading this site get Markdown and JSON instead of this page.

tools: search · get · context

3.0 Privacy, live

Who sees what?

Say your memory holds a note like one of these. Pick one to see what each reader gets back. The examples are fixed on purpose: a free-text box would let anyone probe the filter for gaps.

The filter recognises e-mail addresses (also written as "name [at] host [dot] ca"), phone numbers, street addresses, postal codes, GPS coordinates, card numbers and IBANs, Canadian SIN and US SSN numbers, dates of birth, and passwords or keys. It does not recognise names, schedules or relationships.
