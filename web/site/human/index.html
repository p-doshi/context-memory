The problem

Every conversation starts from zero.

01

Assistants forget

Close a session and the decisions, dead ends and fixes are gone. Next time you explain it all again.

02

Context is scattered

Sessions on a laptop, a cluster and lab servers; two Claude accounts; Perplexity threads; repositories and notes. No single place knows it all.

03

Pasting context is costly

Copying background into every prompt burns tokens and time, and the sensitive parts go along with it.

How it works

Four steps, all on your machine.

  1. 1

    Capture

    Sessions from every machine arrive over an encrypted SSH link; chats, code and notes are read where they live.

  2. 2

    Understand

    Everything is split into passages, turned into searchable vectors by a model on your own GPU, and linked into a knowledge graph.

  3. 3

    Remember

    One store on your laptop. When a file changes, the old version is retired, not deleted, so history survives.

  4. 4

    Answer

    Any assistant asks; it gets the relevant passages, where each came from, and whether the source file still says so.

Design

The hard parts, and how they're handled.

Privacy

Notes and chats hold names, addresses, unpublished work.

Everything stays on your laptop: no cloud database, no hosted AI service in between. Before anything reaches a cloud assistant, a privacy filter replaces contact details, precise locations, card numbers and passwords.

0 cloud databases or hosted AI models

Security

A memory reachable from anywhere is a target.

Other machines connect only through SSH, each with its own access token you can revoke. The private memory never faces the internet, and a firewall rule stops the memory's own software from opening outside connections. This website runs from a separate copy holding only what was chosen for publication.

2 separate stores: private, and public-only

Speed

Search has to feel instant inside an assistant's workflow.

Vectors are held in memory and keyword search is narrowed before ranking. Measured on a laptop: a warm search returns in about a sixth of a second, and in about a fifth from a remote lab server through the SSH tunnel.

152 ms median search on the laptop · 219 ms remote

Trust

An AI's answer can't be taken on faith.

Every passage carries its source. Passages from files are re-checked against the file when they are used and marked verified, stale or missing, so outdated knowledge shows itself.

3 states on every file passage: verified · stale · missing

Accuracy

Exact names and fuzzy questions need different kinds of search.

Meaning-based search and keyword search run together and their rankings are merged. On 30 test questions the right document was in the top five 90% of the time, against 75% for meaning alone (small test, wide error bars).

90% top-5 hit rate, combined search

Cost

It should run on hardware you already own.

The embedding model and this site's answer model both run on one 6 GB laptop graphics card. No paid APIs, no subscription, no per-question fees.

6 GB GPU (GTX 1660 Ti) does all of it

# after installing uv
git clone https://github.com/p-doshi/context-memory
cd context-memory && uv sync --locked --extra embed
uv run cmh init --code ~/my-repo --download-model
uv run cmh daemon --once
uv run cmh search "how did I set up training"
