# Context Memory Harness

> A local memory shared by AI assistants: every coding session, chat, codebase and document goes into one store on the owner's laptop, and assistants on any machine retrieve from it with sources attached. Open source (MIT).

Repository: https://github.com/p-doshi/context-memory
Replication guide (six commands, no code): [/guide.md](/guide.md)
Machine-readable pipeline: [/pipeline.json](/pipeline.json)

## Problem

AI assistants forget everything between sessions; a person's context is scattered across machines, accounts and tools; pasting background into prompts costs tokens and exposes sensitive details.

## How it works

1. Capture: sessions from every machine arrive over SSH; chats, code and notes are read where they live.
2. Understand: content is split into passages, embedded on the local GPU, and linked into a knowledge graph.
3. Remember: one store on the laptop; changed files retire old passages instead of deleting them.
4. Answer: an assistant gets the relevant passages, their sources, and whether each source file still says so.

## Design: the hard parts

- Privacy: no cloud database or hosted AI model; a deterministic filter replaces contact details, precise locations, card numbers and credentials before anything reaches a cloud assistant.
- Security: SSH only, one revocable token per device; the private memory never faces the internet and a firewall rule blocks its software from outside connections; this site serves a separate public-only copy.
- Speed: in-memory vectors and pre-filtered keyword search; median warm search 152 ms on the laptop, 219 ms from a remote server through the SSH tunnel.
- Trust: every passage carries its source; file passages are re-checked at answer time (verified, stale, missing).
- Accuracy: keyword and meaning-based rankings merged; top-5 hit rate 0.90 vs 0.75 for meaning alone on 30 test questions (wide confidence intervals).
- Cost: embedding and this site's answer model run on one 6 GB GPU (GTX 1660 Ti); no paid APIs.

## Pipeline

1. **sources**: Claude Code sessions from every machine (session hook, SSH only), claude.ai and Perplexity conversations (logged-in local browser), git-tracked code, Markdown docs.
2. **ingress**: secret scanner (reject; chat logs redacted), owner-listed folders only.
3. **chunking**: Markdown at headings; Python at classes and methods with line ranges.
4. **embedding**: Qwen3-Embedding-0.6B, pinned revision, float32, local GPU (GTX 1660 Ti), offline.
5. **storage**: SQLite (metadata, provenance, FTS5, hash-chained audit log) and LanceDB (vectors); changed sources retire old chunks, nothing is deleted.
6. **graph**: projects, documents, modules, classes, methods, imports; each edge cites its evidence chunk.
7. **retrieval**: vector, BM25, or hybrid via reciprocal rank fusion, k = 60 (Gordon V. Cormack, Charles L A Clarke, Stefan Buettcher (2009), doi:10.1145/1571941.1572114). Owner's corpus, about 12,000 chunks, 30 queries: recall@5 hybrid 0.90 [95% CI 0.80, 0.98], vector 0.75 [0.58, 0.90]. Warm hybrid search about 150 ms locally (median).
8. **verification**: results from local files re-checked at query time: verified, stale or missing; chats unverified.
9. **disclosure**: deterministic Disclosure Gate per recipient class (owner, local model, cloud model, public) withholds contact, precise location, financial and credential attributes.
10. **delivery**: MCP for Claude Code on any machine (SSH tunnels), session-start context pack, private owner console, and this public site served from an exported public copy.

## Endpoints on this site

All JSON unless noted. No authentication; rate-limited per client.

- `POST /api/agent`: AG-UI run (https://docs.ag-ui.com). Body: `RunAgentInput` (`threadId`, `runId`, `messages`, `tools`, `context`, `state`). Response: `text/event-stream` with `RUN_STARTED`, `STEP_STARTED`, `TOOL_CALL_START/ARGS/END/RESULT` (the retrieved excerpts), `TEXT_MESSAGE_START/CONTENT/END` (the answer, citing excerpts as [n]), `RUN_FINISHED`.
- `GET /api/search?q=<text>`: excerpts with `project`, `kind`, `where`, `status`, `snippet`.
- `GET /api/projects`, `GET /api/graph` (module import graph), `GET /api/stats`.
- `POST /api/gate` with `{"text": "..."}`: what each recipient class would receive.

## What this site does not show

Only projects the owner marked public, and only code and notes (no chats). Personal attributes are withheld by the gate. Answers are generated by a small local model from the excerpts; check them against the cited excerpts.
